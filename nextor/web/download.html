Instaladores por plataforma

O cerebro e os dados continuam na sua maquina. Nos desktops, o empacotador sobe o servico local e abre a janela; no celular, o app conecta ao seu Nextor pela rede Wi-Fi de casa ou por VPN privada.

Desktop

Windows

Instalador .msi / .exe (Tauri) ou janela dedicada via Edge/Chrome (--app). Sobe o servico local na porta 5005 e abre o painel.

python scripts/empacotar_desktop.py --plataforma windows
Desktop

Linux

Pacotes .AppImage e .deb (Tauri) para Ubuntu, Debian, Fedora e Arch. Empacota o servico local com a interface PWA.

python scripts/empacotar_desktop.py --plataforma linux
Desktop

macOS

Imagem .dmg e bundle .app (Apple Silicon e Intel) com inicializacao automatica do servico local.

python scripts/empacotar_desktop.py --plataforma macos
Mobile

Android

Instalavel direto pelo Chrome ("Instalar aplicativo") ou como pacote .apk (Capacitor / TWA) conectando por Wi-Fi ou VPN.

python scripts/empacotar_desktop.py --plataforma android
Mobile

iPhone e iPad (iOS)

Abra no Safari, toque em Compartilhar e em "Adicionar a Tela de Inicio". Integra com Siri e app Atalhos para voz.

Safari > Compartilhar > Adicionar a Tela de Inicio
Universal

Navegador Web

Acesso imediato em qualquer sistema pela rede local (http://IP:5005/painel) com cache offline do shell.

http://localhost:5005/painel

Acesso fora de casa e seguranca

Nunca abra portas no roteador para expor o Nextor na internet publica. Para usar o app no Android, iPhone ou notebook fora de casa, conecte os aparelhos em uma rede VPN privada (como Tailscale ou WireGuard) e informe o IP da VPN na secao Conexao do painel.
